# What JobPilot is

JobPilot is a private command center for one person's job search. It was created so applications, resumes, follow-ups, and interview practice live in one place instead of a spreadsheet, a notes app, and a pile of browser tabs.

A search gets messy once it leaves the first few applications. Roles sit in different statuses, deadlines pass, and it is hard to see whether anyone is writing back. JobPilot keeps that record and the writing that goes with it.

## What it does

- Sign-in, a profile, settings, and a password reset that works while signed out.
- A board with Wishlist, Applied, Interview, Offer, and Rejected. Cards can be dragged or moved with a control.
- An application record: company, role, salary, link, notes, contacts, and a timeline.
- More than one resume, uploaded as a PDF or pasted as text.
- Resume tailoring that scores a match and lists missing keywords.
- Cover letters in a chosen tone.
- Interview questions, practice answers, and feedback.
- Reminders and follow-up drafts, plus a calendar of dates.
- A dashboard of applications per week, response rate, interview rate, and the funnel.
- CSV import and export.
- A job-link parser that fills in company and role from common posting URLs.
- Dark mode and a layout that works on a phone.

AI can use OpenAI, Anthropic, or a built-in mock, selected by environment. The mock is enough to use the writing tools without an API key.
